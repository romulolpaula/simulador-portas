O projeto Bits & Gates consiste em um simulador interativo de circuitos lógicos, idealizado e desenvolvido como parte das atividades acadêmicas do curso de Engenharia da Computação da UNIVAP. O objetivo do projeto é aplicar e consolidar conceitos de Lógica Digital, Programação Orientada a Objetos e desenvolvimento de interfaces gráficas, por meio da criação e simulação visual de portas lógicas.
A aplicação permite ao usuário montar circuitos digitais de forma intuitiva, conectando entradas, portas lógicas e saídas, com avaliação automática dos sinais e representação visual dos estados lógicos.

# Funcionalidades Principais

### Simulação de Portas Lógicas
Suporte às portas AND, NAND, OR, NOR, XOR, XNOR e NOT.

### Criação Dinâmica de Circuitos
Inserção de entradas, portas lógicas e saídas diretamente na interface gráfica.

### Conexões Visuais Interativas
Ligação entre componentes por meio de fios gráficos, com atualização automática da posição.

### Avaliação em Tempo Real
Propagação dos sinais lógicos (0/1) ao longo do circuito, com indicação visual de estado
(ligado = verde, desligado = cinza).

### Organização Automática em Colunas Lógicas
Distribuição das portas em camadas, respeitando a lógica de dependência entre entradas e saídas.

### Validação de Conexões
Prevenção de ciclos lógicos e conexões inválidas no circuito.

### Criação da Tabela Verdade
Organização em uma tabela demonstrando os possíveis resultados para cada entrada.

### Integração do Mapa de Karnaugh
Simulador de Mapa de Karnaugh montado pelo usuário. 

# Tecnologias Utilizadas

- Linguagem de Programação: C#

- Interface Gráfica: WPF (Windows Presentation Foundation)

- Markup: XAML

- Paradigmas: Programação Orientada a Objetos

- Conceitos Aplicados: Lógica Digital, Simulação de Circuitos, Modelagem de Sistemas
